# AI 辅助完成简单 Python 脚本：文件分类整理工具

## 一、项目目标

本项目使用 Python 编写一个文件批处理脚本，根据文件扩展名，将指定文件夹第一层中的文件自动分类到不同目录。

分类规则如下：

| 分类目录 | 文件示例 |
|---|---|
| `images` | `.jpg`、`.png`、`.gif` |
| `documents` | `.txt`、`.md`、`.pdf`、`.docx` |
| `code` | `.py`、`.ipynb`、`.js`、`.cpp` |
| `archives` | `.zip`、`.rar`、`.7z` |
| `media` | `.mp3`、`.wav`、`.mp4` |
| `others` | 未配置的其他扩展名 |

## 二、安全设计

脚本默认处于预览模式，只显示准备移动的文件，不会修改文件夹。只有添加 `--execute` 参数后才会真正移动文件。

当目标目录中已经存在同名文件时，脚本会自动添加 `_1`、`_2` 等序号，避免覆盖原文件。

脚本只处理目标文件夹第一层的普通文件，不递归处理子目录。

## 三、使用方法

### 1. 查看帮助

```bash
python file_organizer.py --help
```

### 2. 预览整理当前文件夹

```bash
python file_organizer.py
```

### 3. 预览指定文件夹

Windows PowerShell：

```powershell
python file_organizer.py "C:\Users\ASUS\Desktop\test_files"
```

WSL：

```bash
python file_organizer.py /mnt/c/Users/ASUS/Desktop/test_files
```

### 4. 确认预览无误后正式执行

Windows PowerShell：

```powershell
python file_organizer.py "C:\Users\ASUS\Desktop\test_files" --execute
```

WSL：

```bash
python file_organizer.py /mnt/c/Users/ASUS/Desktop/test_files --execute
```

## 四、运行测试

将 `file_organizer.py` 和 `test_file_organizer.py` 放在同一目录，然后执行：

```bash
python -m unittest -v test_file_organizer.py
```

测试覆盖：

1. 扩展名分类；
2. 预览模式不会移动文件；
3. 正式模式能够移动文件；
4. 同名文件不会被覆盖。

## 五、核心知识点

- `pathlib.Path`：处理跨平台文件路径；
- `Path.iterdir()`：遍历文件夹内容；
- `Path.suffix`：获取文件扩展名；
- `Path.mkdir()`：创建分类目录；
- `shutil.move()`：移动文件；
- `argparse`：解析命令行参数；
- `unittest`：编写自动化测试。

## 六、AI 助手的辅助过程

AI 助手帮助完成了需求拆分、程序结构设计、代码编写、安全性改进和测试设计。人工需要检查分类规则，先使用预览模式确认操作范围，再决定是否正式执行。
